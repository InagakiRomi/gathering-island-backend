# Gathering Island Backend

**Gathering Island（聚會島）** 是一套支援「舉辦、搜尋、報名」線下聚會活動的後端服務。以 **NestJS + TypeScript** 實作，對前端或第三方客戶端提供 REST API：一般使用者可管理自己的活動與報名；主辦者可檢視報名狀況；管理員則可維運帳號、角色與大量資料檢核。

線上 API 文件見 [Swagger](https://gathering-island.onrender.com/api)。

---

## 產品能做什麼

| 面向               | 說明                                                                                                                                           |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **探索聚會**       | 公開查詢聚會列表與單筆詳情，支援分頁、排序與多條件篩選（狀態、類型、標籤、關鍵字等），方便使用者找到想參加的活動。                             |
| **主辦與維護**     | 登入後可建立、更新聚會，將活動標記為已結束，或以軟刪除封存／恢復，避免誤刪歷史資料。                                                           |
| **我的聚會**       | 「我建立的」與「我已參加的」兩類清單，各自支援與公開列表相同的篩選與分頁，方便主辦方與參與者管理行程。                                         |
| **報名流程**       | 報名與取消報名會檢查活動狀態、截止時間與人數上限；主辦方或管理員可查詢該活動的已報名帳號基本資料，利於現場簽到或聯絡。                         |
| **跨使用者檢視**   | 可依「指定使用者」查詢其建立的聚會、或已報名參加的聚會；**本人**可查自己，**管理員**可查任意使用者，利於客服與營運盤點。                       |
| **帳號與個人資料** | 註冊、登入、Refresh 換發 Access Token、登出；登入者可讀取與更新自己的顯示名稱。                                                                |
| **管理後台能力**   | 管理員可分頁列出使用者、依 ID 查詢／更新名稱、調整角色（含保護最後一位管理員等規則）；標籤可全表列出（含被引用次數）、依條件刪除未使用之標籤。 |
| **標籤**           | 依名稱查詢標籤 ID、建立標籤（若已存在則回傳既有資料），讓建立聚會時能穩定關聯分類。                                                            |
| **大量資料檢核**   | 管理員可上傳 `Gathering.xlsx`，由後端解析並以與建立聚會相同的規則驗證每一列，在正式匯入前先行除錯。                                            |
| **排程與品質**     | 定時任務自動更新聚會狀態；API 層級統一成功與錯誤回應格式（Interceptor + Filter），並以 Swagger 描述端點。                                      |

## 技術棧

- **NestJS**、**MikroORM**、**SQLite**：後端與資料庫
- **Passport + passport-jwt**：JWT 驗證
- **bcrypt**：密碼雜湊
- **class-validator + class-transformer**：DTO 驗證
- **Joi**：環境變數驗證（`@nestjs/config`）
- **@nestjs/swagger**：API 文件
- **@nestjs/schedule**：Cron 排程
- **xlsx**：Excel 解析
- **dayjs**：日期處理
- **Jest**、**supertest**：測試

---

## 身分驗證

- `@Public()`：標記無需登入的公開路由（如登入、註冊）
- `@Roles('admin')`：角色權限控管
- `@GetUser()`：取得目前登入的使用者
- 雙 Token 機制（Access + Refresh），Refresh Token 可置於 HttpOnly Cookie（登入／換發時寫入，登出時清除）

## 模組與 API 範圍（摘要）

| 模組           | 功能摘要                                                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **auth**       | 註冊、登入、Refresh、登出                                                                                                      |
| **gatherings** | 公開列表與詳情；我的／已參加；建立、更新、軟刪除、恢復、手動結束；報名／取消；主辦或管理員查看參加者；Excel 格式檢查（管理員） |
| **tags**       | 依名稱查 ID、建立；全列表與刪除（管理員）                                                                                      |
| **users**      | 目前使用者個人資料與更新名稱；管理員之使用者列表、單筆查詢、更新名稱與角色；依使用者 ID 查詢其建立／參與的聚會（本人或管理員） |

完整路徑與請求格式請以 Swagger 為準。

```bash
npm install

```
